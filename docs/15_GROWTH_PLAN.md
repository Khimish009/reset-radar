# 15 — Practical launch and growth plan

## Main funnel

**Useful sourced event or explainer → public website / GitHub → Telegram channel subscription**. Telegram channel is the primary CTA. Do not promote bot private chat as functional until `/start` exists. The site adds searchable explanatory content and event history, not anonymous visitor profiling.

### Before promotion

- Owner verifies channel/bot handles, profiles, independent disclaimer, pinned introduction, and exact public website/GitHub links.
- Run staging and production dry-run; source claims accurate; real channel sends only after explicit owner authorization.
- Publish a few helpful evergreen explainers (five-hour vs weekly personal quota; public bonus reset vs ordinary per-user reset; what confirmed delivery means). Mark examples/historical screenshots accordingly.
- Release static website with clear hero, CTA, methods, history, correct metadata; verify mobile and stale displays.

### First month — free distribution

1. Put site and Telegram links in repo README, GitHub project About/website field, own technical profile where appropriate.
2. Publish concise, useful evidence-backed posts on permitted Claude/Codex developer communities (Reddit/Discord/X/Telegram tech chats), no unsolicited DMs or link-only spam.
3. Share legitimate monthly digest of *observed* events with cited sources, not false urgency; website history is its supporting reference.
4. Politely contact upstream tracker owners about attribution, reciprocal mention or small collaboration; never imply endorsement.
5. In GitHub Discussions/Issues accept bug reports for missed/corrected events and requests for additional providers. Avoid leaking secrets, internal account details or unverifiable screenshots.

### Measure

Quality: wrong-alert count (target zero), false confidence incidents, number of unknown statuses, time from original source to observed to alert, stale hours, duplicate count.

Reach: subscribers, Telegram views/forwards, GitHub stars/traffic if available, website aggregate pageview estimates if owner explicitly approves a privacy-safe method. Don't collect individual tracking IDs by default.

### Paid promotion (later)

After stable data quality and published website, optionally small capped tests in relevant tech channels; Telegram Ads only with compliant functional destination. Measure cost per *retained engaged* subscriber, not raw fake member counts.

### Avoid

Spam in communities/DMs, bought followers, fabricated real-time claims, misleading predictions, copying upstream tracker content without attribution, ads on nonfunctional bot or website, scraping personal account data.
