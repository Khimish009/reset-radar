# Сохранённые доказательства Stage 0 — 2026-10-21

Этот каталог подготовлен для продолжения в новой сессии. Он не зависит от `/tmp`, сети, npm или секретов. Все наблюдения относятся к 21 октября 2026 года; текущую доступность и неизменность upstream они не гарантируют.

- [manifest.json](manifest.json) перечисляет 36 сохранённых артефактов, SHA-256 оригиналов там, где применимо, SHA-256 сохранённых файлов и удалённые поля.
- `snapshots/` содержит **captured projections**: Claude status/resets/sources, две cursor-страницы; CodexReset resets; status/resets альтернативы; две OpenAPI схемы без описательных аннотаций.
- `headers/` содержит выбранные реальные HTTP headers без cookies и CDN telemetry. Заголовки отдельных ответов сохранены раздельно, включая различие Cache-Control у 200/304 альтернативы.
- Три robots.txt сохранены без изменений.
- `before/` содержит три документа до Stage 0; [stage0-review.diff](stage0-review.diff) — финальный diff исследования до подготовки этой передачи. Последующие handoff-добавления в этот исторический diff не входят.
- [verify.py](verify.py) проверяет целостность архива, ключевые структурные факты и captured-примеры из основного документа.

Запуск из корня проекта:

```sh
python3 docs/evidence/stage0-2026-10-21/verify.py
```

Полные чужие HTML-страницы, редакционные summaries, тексты постов и длинные provenance notes не переносились. Для JSON manifest хранит hash **исходного** тела отдельно от hash **сокращённого** файла. Они ожидаемо различаются. Эти проекции **не являются полными parser fixtures**: часть обязательных полей исходной схемы удалена. Не подменять удалённый текст пустой строкой и не называть результат оригинальным ответом.

По Claude conditional status известен HTTP 200 с новым ETag только из вывода команды субагента; отдельные вторые headers/body не сохранялись. Не создавать для них фиктивный capture. Условные Codex GET вернули 304 с пустым телом; для Claude 304 не наблюдался. Реальные correction/withdrawal/date-only переходы не получены.

Правила fair use и источники: [журнал](../../11_SOURCES.md), [контракты](../../04_EXTERNAL_APIS.md). Интерпретация событий: [truth table](../../22_STAGE0_TRUTH_TABLE.md). Контекст следующей сессии: [handoff](../../23_SESSION_HANDOFF.md).

На завершение Stage 0 архив под `docs/` исключался `.gitignore`. В разрешённом Stage 1 это исправлено: документация и архив видимы Git как untracked, но автоматического добавления в index, коммита или push нет. Новый clone получит их только после отдельно разрешённого коммита и push; пока открывай **эту же папку** или переноси папку целиком. Сохранённые snapshots, headers и manifest не менялись.
