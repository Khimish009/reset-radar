# Prompt for Codex after each stage

Проверь текущий Git diff и сделанные изменения на соответствие `AGENTS.md` и требованиям. Укажи ошибки, риски, незакрытые тесты и то, что не было реально проверено (API/Telegram/Cloudflare). Для каждой найденной проблемы дай конкретный путь и файл. Покажи `git status`, выполненные команды, результаты typecheck/lint/tests; уточни, не было ли публикаций, деплоев, пушей или изменений секретов. Не выполняй следующую стадию и не отправляй в main без моего отдельного разрешения. Отдельно проверь Claude и Codex сценарии, source attribution и наличие провайдер-специфичного bootstrap.
