# Generic prompt for a separately owner-approved next stage

**Use only after the current stage is accepted.** Replace `{N}` with the exact approved stage number and choose a branch approved by the owner.

> Прочитай `AGENTS.md`, обновлённые `docs/*.md`, `manual/OWNER_CHECKLIST.md` и текущий `git status`. Выполни **только Stage {N}** из `docs/08_DEVELOPMENT_PLAN.md`, соблюдая критерии готовности и все правила безопасности. Не начинай следующий этап; не делай удалённых миграций, пушей, PR, секретов или деплоя без отдельного одобрения. Запусти релевантные тесты/типизацию/линт/билд, обнови документацию, дай детальный отчёт с фактами и рисками и остановись.
